ghbdtn vbh - a simple project that I think is most useful and that I use in my daily life, it helps save me a little time and a bunch of stress

About the project

You start typing in one language while the keyboard is still in another layout and the app fixes the word on the spot.

ghbdtn rfr ltkf hello becomes «привет как дела hello».

It works with any keyboard layout macOS knows, not only Russian and English
