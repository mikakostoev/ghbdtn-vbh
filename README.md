# landing — the branch behind ghbdtnvbh.app

GitHub Pages publishes this branch as it is: the files in the root here are the site, and nothing else is in it,
so no source code of the app leaks into the published URLs.

Edit `index.html` to change the site — one static page, no build step, no dependencies. `icon-light.png`,
`icon-dark.png` and `demo.gif` are the only binaries; the gif is recorded by `Tools/demo.sh` on `main`.

The app itself lives on `main`, which holds no site files.
