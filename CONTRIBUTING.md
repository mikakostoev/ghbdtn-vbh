# Как помочь проекту

*Contributions are welcome in Russian or English. The short version: `./test.sh` must stay green, and the app must
stay free of networking code.*

## С чего начать

```bash
git clone https://github.com/mikakostoev/layout-switcher.git && cd layout-switcher
./build.sh && open LayoutSwitcher.app
```

Нужны Xcode или Command Line Tools, macOS 13+. Задачи для первого вклада помечены
[good first issue](https://github.com/mikakostoev/layout-switcher/labels/good%20first%20issue) —
берите любую, отпишитесь в ней, что взяли.

## Что проверять перед PR

- `./test.sh` — сборка, самотест и прогон на тестовых текстах. На `Tests/chat-*.txt` должно оставаться
  **0 ложных переключений**; если вы меняли правила переключения, приложите вывод до и после.
- `Tests/live.sh` — живой набор в тестовое окно, если менялся код вокруг событий клавиатуры или замены текста.
- Новое правило или исправленный случай — добавьте пример в самотест (`--selftest` в `Eval.swift`), чтобы он не
  сломался снова.

## Чего не принимаем

- **Сетевой код** в любом виде: обновления, статистика, отчёты о сбоях. Это главное обещание README, и оно
  проверяется одним `grep`.
- Запись набранного текста на диск, кроме трёх существующих файлов в Application Support.
- Новые зависимости: проект живёт на одном `Package.swift` без пакетов, и так должно остаться.
- Бинарные файлы в репозитории. Единственный — `.github/demo.gif`, и тот пересоздаётся `Tools/demo.sh`;
  иконка рисуется `Tools/icon.swift`.

## Как устроен код

Около тысячи строк в `Sources/LayoutSwitcher/`, читается за вечер:

| Файл | За что отвечает |
|---|---|
| `main.swift` | Event tap, строка меню, замена слова на экране |
| `Buffer.swift` | Текущее слово и пара предыдущих; когда буфер очищается |
| `Layouts.swift` | Раскладки, правила «это слово набрано не в той раскладке», словарь и триграммы |
| `Trigrams.swift` | Таблица частот буквосочетаний; генерируется `Tools/trigrams.py`, руками не правится |
| `Words.swift` | Сленг и аббревиатуры, которых нет в системном словаре |
| `Settings.swift` | Окно настроек и файлы в Application Support |
| `Eval.swift` | `--selftest` и `--eval` |

Стиль: короткие функции, комментарии — про «почему», а не «что». Комментарий `// ponytail:` означает
осознанное упрощение и подсказку, как его развить, если понадобится.

## Новый язык

Таблицы буквосочетаний сейчас есть для русского, английского и украинского. Чтобы переключатель понимал ещё
один язык не только по системному словарю:

1. Добавьте алфавит в цикл в `Tools/trigrams.py`, скачайте `xx_50k.txt` из FrequencyWords, запустите скрипт.
2. Однобуквенные слова языка — в `oneLetterWords` в `Layouts.swift`.
3. Тестовый текст `Tests/chat-xx.txt` из обычной переписки и прогон `--eval` с ним.

## Баг с конкретным приложением

Самые ценные отчёты — «в приложении X слово не заменяется / заменяется не то». Укажите версию macOS,
название приложения и что было набрано; если приложение на Electron или это браузер, скажите какой.
