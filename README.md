# LayoutSwitcher

Автопереключатель раскладки для macOS: набрали `ghbdtn` — получили «привет». Бесплатный, с открытым кодом,
и **ничего никуда не отправляет** — в программе нет ни одной строки сетевого кода.

*A keyboard layout auto-switcher for macOS (Russian ⇄ English and any other pair of layouts). Free, open source,
zero telemetry: the app contains no networking code at all.*

## Почему ему можно доверять клавиатуру

Переключатель раскладки видит всё, что вы печатаете, — иначе он не может работать. Поэтому вопрос не в обещаниях,
а в том, что можно проверить:

- **Нет сети.** Ни обновлений, ни статистики, ни проверки лицензии, ни отчётов о сбоях. Проверка занимает минуту:
  ```bash
  grep -rnE "URLSession|URLRequest|NWConnection|CFSocket|WebKit" Sources/
  ```
  Пусто. Весь код — около тысячи строк на Swift в `Sources/`, его реально прочитать целиком.
- **Набранный текст не хранится.** В памяти лежит только текущее слово (и до трёх коротких слов перед ним) —
  буфер очищается при клике, стрелках, смене окна. На диск он не пишется никогда. «Дневника» нет и не будет.
- **Поля паролей не читаются**: пока система сообщает о защищённом вводе, программа не смотрит на клавиши вообще.
- **Что лежит на диске** — три текстовых файла в `~/Library/Application Support/LayoutSwitcher/`, все видны
  и редактируются в настройках:
  `exceptions.txt` (слова, которые не надо переключать), `words.txt` (слова, которые вы сами сконвертировали
  двойным Option, — чтобы в следующий раз переключались сами; отключается галочкой), `sites.txt` (сайты-исключения).
- **Буфер обмена** используется в одном случае: вы выделили текст и попросили его сконвертировать, а приложение
  не отдаёт выделение через Accessibility (Electron, часть браузеров). Тогда программа нажимает Cmd+C, читает
  текст и тут же возвращает в буфер то, что там было.
- **Разрешение нужно одно** — «Универсальный доступ»: без него macOS не даёт ни видеть нажатия, ни заменять слово.
- **Словарь и статистика локальные.** Слова проверяются системным словарём macOS, незнакомые — по встроенной
  таблице частот буквосочетаний. В таблице только числа, слов из вашего текста там нет и взяться неоткуда.

## Что умеет

- Переключает слово и раскладку, когда слово набрано не в той: `ghbdtn` → «привет», `руддщ` → «hello».
- Слова не из словаря — сленг, имена, жаргон — по статистике букв: `ltdjgcjd` → «девопсов».
- Короткие слова в начале фразы задним числом: `ye ns ghbdtn` → «ну ты привет».
- Капс, аббревиатуры в нижнем регистре (`cif` → «сша», `вты` → `dns`), растянутые «привееет»,
  идентификаторы (`getUserName`, `user_name`), числа (`10ю5` → `10.5`).
- Двойной Option (или одиночный — в настройках) конвертирует последнее слово или выделенный текст. Конвертация сразу после
  автопереключения означает «ты ошибся» — слово попадает в исключения.
- Исключения по приложениям и по сайтам (домен читается через Accessibility, только в момент замены).

## Точность и скорость

Не «поверьте», а прогон, который можно повторить: `./test.sh` набирает каждое слово тестовых текстов в своей
и в чужой раскладке.

- Повседневные тексты (чат, работа, немного кода, 467 слов): **0 ложных переключений**; не переключаются только
  2–3-буквенные слова, читаемые в обеих раскладках, — их исправляет следующее слово.
- 5 700 редких слов и имён из субтитров: 3 ложных переключения.
- Решение принимается в памяти; в обоих прогонах ни одно не заняло больше 10 мс.

## Сборка

Нужны macOS 13+ и Xcode или Command Line Tools.

```bash
./build.sh
```

```bash
open LayoutSwitcher.app
```

При первом запуске выдайте доступ в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».
Чтобы доступ не слетал после пересборки, создайте самоподписанный сертификат для подписи кода с именем
`LayoutSwitcher Local Signing` (Связка ключей → Ассистент сертификации); без него сборка подписывается ad-hoc.

Проверки: `./test.sh` (сборка, самотест, оценка на текстах) и `Tests/live.sh` (живой набор в тестовое окно,
на несколько секунд занимает клавиатуру).
