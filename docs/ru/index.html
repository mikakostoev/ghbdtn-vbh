ghbdtn vbh

привет мир

Автопереключение раскладки для macOS. Бесплатно, открытый код, и ничего никуда не отправляется.

Установка

brew tap mikakostoev/ghbdtn-vbh https://github.com/mikakostoev/ghbdtn-vbh && brew install --cask --no-quarantine ghbdtn-vbh

Или скачать zip и перетащить ghbdtn vbh.app в Программы. macOS 13 и новее, Apple silicon и Intel.

При первом запуске macOS блокирует приложение: нажмите «Открыть всё равно» в Системных настройках → Конфиденциальность и безопасность, затем разрешите его в Универсальном доступе. Приложение откроет окно и проведёт по шагам. За сборкой нет платного сертификата Apple, поэтому после обновления разрешение спрашивается снова.

Что умеет

  • Исправляет слово на месте: ghbdtn → «привет», руддщ → «hello». Любая раскладка, которую знает macOS, не только русская и английская.
  • Понимает сленг и имена, которых нет в системном словаре, по статистике букв: ltdjgcjd → «девопсов».
  • Справляется с Caps Lock, аббревиатурами, идентификаторами вроде getUserName, числами и растянутыми словами.
  • Двойной Option конвертирует последнее слово или выделение вручную.
  • Исключения по словам, приложениям и сайтам.

Почему ему можно доверить клавиатуру

  • Сети нет совсем. Ни обновлений, ни статистики, ни проверки лицензий, ни отчётов о сбоях. Один grep по исходникам не находит ни одной сетевой библиотеки.
  • Код короткий и открытый. Около тысячи строк Swift, читается за вечер.
  • Набранное не хранится. В памяти — слово, которое вы печатаете, и не больше трёх коротких слов перед ним. На диск не пишется.
  • Пароли не читаются. В защищённом поле приложение не смотрит на клавиши вообще.
  • Три текстовых файла в Application Support: исключения, выученные слова и исключённые сайты. Все видны в настройках.

Языки

Работают как русский и английский: украинский, немецкий, французский, испанский, итальянский, португальский, нидерландский, датский, норвежский, шведский, финский, исландский, чешский, польский, венгерский, румынский, болгарский, греческий, турецкий, литовский, иврит, арабский.

Слабее без системного словаря (хорватский, словацкий, эстонский, македонский, албанский, сербский, фарси, грузинский) и для раскладок, чьи буквы совпадают с английскими. Не работает для методов ввода (китайский, японский, корейский), письменностей без пробелов и раскладок с мёртвыми клавишами. Честный список — в README.
